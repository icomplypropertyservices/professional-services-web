# STRICT page template — ALL Professional Services pages (Jack 2026-10-05)

**Non-negotiable.** Applies to hubs, keyword pages, area pages, keyword×place, and every other public HTML page. No thin template variants. Enforce on every ship; reject/fix before merge if any check fails.

## Required on every page
1. **Body copy:** ≥ **800 words** of unique substantive content (not nav/footer/boilerplate alone).
2. **Images:** exactly **3** (or more) relevant images with alt text.
3. **Metadata + tags (complete):**
   - `<title>`
   - meta description
   - Open Graph (at least `og:title`, `og:description`, `og:url`, `og:type`, `og:image`)
   - canonical URL
   - **Schema.org JSON-LD** (appropriate type: ProfessionalService / LocalBusiness / FAQPage / Service as fits)
4. **FAQs** section (kept from prior quality bar)
5. Sitemap entry after ship; SEO scan before/after waves

## Enforcement
- PS Website: template + export must fail closed if word count / image count / meta/schema missing.
- PS SEO: do not mark a URL shippable unless it meets this bar.
